## Product Sales Analysis Using Power BI

##  Project Overview

This project focuses on analyzing **product sales data using Microsoft Power BI** to understand sales performance, identify trends, and generate meaningful business insights. The data was prepared and transformed before creating an interactive dashboard for better visualization and analysis.

##  Tools & Technologies

* Microsoft Power BI
* Power Query
* Data Cleaning
* Data Transformation
* Data Visualization
* DAX

##  Analysis Performed

* Imported and cleaned the sales dataset using Power Query.
* Transformed data to make it suitable for analysis.
* Created interactive visualizations and dashboards.
* Analyzed sales performance across different categories and regions.
* Identified sales trends and patterns.
* Used filters and slicers for interactive analysis.
* Created calculated measures using DAX.

## Dashboard Features

The Power BI dashboard provides insights into:

* Total Sales
* Sales by Product Category
* Sales by Region
* Sales Trends
* Product Performance
